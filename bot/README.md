# Chatty — бот для разговорной практики английского

Telegram-бот: отправляешь голосовое на английском, бот исправляет ошибки и отвечает
**только голосом**, чтобы ты учился понимать на слух. Текст открывается по кнопке, и любое
слово из него можно перевести и сохранить в словарь.

```
🎙 твоё голосовое
   → faster-whisper (распознавание, локально)
   → Claude (исправления + оценка + ответ + перевод)
   → 💡 Hello, <s>that</s> <b>it</b>'s been a while.      [Объяснить] [Оценка]
   → edge-tts → ffmpeg → 🔊 голосовой ответ без текста    [Текст] [Помощь]
                                                             │
          мини-приложение: текст, нажал на слово → перевод и 🔖 в словарь
```

## Что умеет
- **Голосовые и текст**: можно говорить или писать.
- **💡 Исправленная фраза**: удалённое ~~зачёркнуто~~, добавленное **выделено**.
  **Объяснить**: почему так, по-русски. **Оценка**: балл 1–10 и комментарий.
- **Голосовой ответ без текста**: бот поддерживает разговор и в конце задаёт вопрос.
- **Текст**: открывает мини-приложение с репликой бота.
  - Нажми на любое слово, и появится карточка: словарная форма (`happening` → `happen`),
    перевод по контексту, 🔊 произношение, 🔖 сохранить в словарь.
  - **Перевести по словам**: подписывает перевод под каждым словом.
  - **Перевод целиком**: перевод всей реплики.
  - Сохранённые слова подчёркнуты.
- **Помощь**: три варианта ответа (от простого к сложному) с переводом и полезная конструкция.
- `/add слово` — добавить своё слово (перевод подставится сам), `/dict` — открыть словарь, `/del` — удалить слово.
- `/export` — файл для **импорта в приложение «Мои слова»** из этого репозитория (Статистика → Импорт).
- `/reset` — начать разговор заново. Бот помнит последние 20 реплик.

## Запуск

### 1. Что понадобится
- Python 3.10+ и **ffmpeg** (`sudo apt install ffmpeg` / `brew install ffmpeg` / на Windows: `winget install ffmpeg`).
- **Токен бота**: напиши [@BotFather](https://t.me/BotFather) → `/newbot` → он пришлёт токен.
- **Ключ Claude API**: [platform.claude.com](https://platform.claude.com/) → API keys. API платный,
  оплата за использование.

### 2. Установка
```bash
cd bot
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # и впиши TELEGRAM_BOT_TOKEN и ANTHROPIC_API_KEY
```

### 3. Запуск
```bash
python main.py
```
Пока скрипт работает, бот отвечает. При первом голосовом скачается модель Whisper
(`small` весит около 0,5 ГБ), поэтому первый ответ будет долгим.

### 4. Мини-приложение «Текст»
Telegram открывает мини-приложения только по **https**. На своём компьютере проще всего
использовать бесплатный туннель [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/)
(регистрация не нужна):
```bash
cloudflared tunnel --url http://localhost:8080
```
Он напечатает адрес вида `https://….trycloudflare.com`. Впиши его в `WEBAPP_URL` в `.env`
и перезапусти бота. Адрес меняется при каждом запуске туннеля. Постоянный адрес можно получить
на своём сервере с доменом.

Без `WEBAPP_URL` бот тоже работает: кнопка «Текст» покажет текст в подписи к голосовому,
а слова можно будет выбрать кнопками.

### 5. Закрой бота от чужих
Напиши боту что-нибудь, затем впиши свой id в `ALLOWED_USERS` в `.env` и перезапусти бота.
Узнать id можно у [@userinfobot](https://t.me/userinfobot). Без этого любой, кто найдёт бота,
будет тратить деньги с твоего ключа.

## Настройки (`.env`)
| Переменная | По умолчанию | Что это |
|---|---|---|
| `CLAUDE_MODEL` | `claude-opus-5-5` | модель Claude |
| `CLAUDE_EFFORT` | `low` | `low`: быстрый ответ; `medium`/`high`: дольше думает, точнее разбор |
| `WHISPER_MODEL` | `small` | `tiny`/`base`: быстрее, но хуже; `medium`: точнее, но медленнее |
| `WHISPER_LANGUAGE` | `en` | пусто — автоопределение языка (если иногда говоришь по-русски) |
| `TTS_VOICE` | `en-US-AriaNeural` | список голосов: `edge-tts --list-voices` (`en-GB-SoniaNeural` — британский) |
| `TTS_RATE` | `-5%` | скорость речи: `-20%` медленнее, `+10%` быстрее |
| `WEBAPP_URL` | — | https-адрес мини-приложения (см. шаг 4) |
| `WEBAPP_PORT` | `8080` | порт, на котором бот отдаёт мини-приложение |

## Устройство
| Файл | Что делает |
|---|---|
| `main.py` | обработчики Telegram (aiogram 3): голос, текст, команды, кнопки |
| `webapp.py` | сервер мини-приложения (aiohttp): страница и API с проверкой подписи Telegram |
| `webapp/index.html` | мини-приложение «Текст» |
| `tutor.py` | запросы к Claude со структурированным ответом (Pydantic-схемы `Turn`, `WordList`) |
| `speech.py` | распознавание (faster-whisper) и озвучка (edge-tts + ffmpeg → OGG/Opus) |
| `storage.py` | SQLite: история, реплики бота, словарь, экспорт для приложения |

## Ограничения, о которых стоит знать
- **Whisper иногда сам «чинит» речь**: может распознать `I go to shop` как `I go to the shop`,
  и тогда бот эту ошибку не увидит. Модель `medium` ошибается так реже, но работает медленнее.
- **edge-tts** — неофициальный доступ к голосам Microsoft Edge. Он бесплатный и без ключа, но
  может перестать работать. Если озвучка не сработает, бот пришлёт ответ текстом.
- Бот работает через long polling, пока запущен `main.py`. Чтобы он работал круглосуточно, его
  нужно запустить на сервере или VPS.
