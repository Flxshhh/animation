# Мои слова — тренажёр английских слов

Сайт-приложение (PWA) для телефона: записываешь английское слово — он сам подставляет перевод,
транскрипцию и примеры употребления, а потом тренирует тебя.

## Возможности
- **Автоперевод** (Google Translate, запасной — MyMemory) + варианты перевода.
- **Произношение**: транскрипция IPA, приблизительная русская транскрипция и кнопка 🔊 (озвучка телефона).
- **Примеры употребления** по кнопке «Примеры» (dictionaryapi.dev), каждый пример можно перевести.
- **Тренажёр**: выбор перевода, обратный выбор, написание слова, на слух, карточки, микс.
- **Статистика**: уровни знания, точность, серия дней, активность за неделю, трудные слова.
- **Удаление** выученных слов (из списка и прямо из итогов тренировки).
- Экспорт/импорт резервной копии в JSON.

Данные хранятся в `localStorage` браузера — без сервера и регистрации.

## Как открыть на телефоне
1. GitHub → репозиторий → **Settings → Pages**.
2. Source: **Deploy from a branch**, ветка с приложением, папка `/ (root)` → Save.
3. Через минуту сайт будет доступен по адресу `https://<user>.github.io/<repo>/`.
4. Открой его на телефоне и выбери «Добавить на главный экран» — появится иконка как у приложения.

Локально: `python3 -m http.server` в папке проекта и открыть `http://localhost:8000`.
