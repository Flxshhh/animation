# Мои слова — тренажёр английских слов

Сайт-приложение (PWA) для телефона: записываешь английское слово — он сам подставляет перевод,
транскрипцию и примеры употребления, а потом тренирует тебя. **Работает без интернета.**

## Возможности
- **Встроенный словарь** (41 710 слов): перевод с ударением, варианты, часть речи,
  транскрипция IPA и русскими буквами, английские примеры. Понимает формы слов: `went → go`, `cats → cat`.
- **Без интернета**: после первого открытия приложение и словарь сохраняются на телефоне.
  Слово, которого нет в словаре, добавится и переведётся автоматически, когда появится сеть.
- **Онлайн-запасной вариант**: Google Translate / MyMemory / dictionaryapi.dev — для редких слов и фраз.
- **Произношение** — кнопка 🔊 (голос телефона).
- **Тренажёр**: выбор перевода, обратный выбор, написание слова, на слух, карточки, микс.
- **Статистика**: уровни знания, точность, серия дней, активность за неделю, трудные слова.
- **Удаление** выученных слов, экспорт/импорт резервной копии.
- **Общение** — разговорная практика с нейросетью (Google Gemini, бесплатный ключ):
  говоришь голосом → видишь исправленную фразу (~~лишнее~~ / **нужное**), «Объяснить», «Оценка» →
  собеседник отвечает **только голосом** → «Текст» открывает ответ: нажми на слово — перевод в контексте
  и кнопка «В словарь» (слово сразу попадает в «Мои слова»); «Перевести по словам», «Перевод целиком»,
  «Помощь» — варианты ответа. Нужен интернет.

### Как включить «Общение»
1. Открой [aistudio.google.com/apikey](https://aistudio.google.com/apikey), войди через Google и нажми **Create API key**.
2. В приложении открой вкладку **Общение** и вставь ключ. Он хранится только в этом браузере.
3. Разреши доступ к микрофону, когда браузер спросит.

На бесплатном тарифе Gemini есть дневной лимит запросов; когда он кончается, приложение само пробует
другую модель. Google может использовать данные бесплатного тарифа для улучшения моделей.

Слова хранятся в `localStorage` браузера — без сервера и регистрации.

## Как открыть на телефоне (GitHub Pages)
1. GitHub → репозиторий → **Settings → Pages**.
2. **Source: Deploy from a branch**, ветка `claude/english-words-learning-app-xt8ocx`, папка `/ (root)` → **Save**.
3. Через 1–2 минуты сайт откроется по адресу **https://flxshhh.github.io/animation/**.
4. Открой его на телефоне **один раз с интернетом** и выбери «Добавить на главный экран».
   Дальше иконка открывает приложение и без сети.

GitHub Pages на бесплатном аккаунте работает только для **публичных** репозиториев.

## Словарь
Файлы `dict/*.json` собираются скриптом `tools/build_dict.py` из открытых источников:
- переводы — [OpenRussian](https://github.com/Badestrand/russian-dictionary) (CC BY-SA 4.0);
- транскрипции — CMU Pronouncing Dictionary (npm `cmu-pronouncing-dictionary`);
- примеры — WordNet 3.0, Princeton University (npm `wordnet-db`).

Локальный запуск: `python3 -m http.server` в папке проекта → `http://localhost:8000`.
